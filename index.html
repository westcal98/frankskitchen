For the best experience install Frank's Kitchen as a standalone app on your device. The installed app has its own storage that won't be affected by browser privacy settings like Clear Data on Exit.

Android (Chrome)
  1. Open frankskitchen.westcal98.workers.dev in Chrome
  2. Tap the three dot menu (⋮) in the top right
  3. Tap "Add to Home Screen" or "Install App"
  4. Tap Install on the prompt
  5. Frank's Kitchen will appear on your home screen and in your app drawer like a native app
iOS (Safari)
  1. Open frankskitchen.westcal98.workers.dev in Safari (must use Safari — Chrome on iOS cannot install PWAs)
  2. Tap the Share button (box with upward arrow)
  3. Scroll down and tap "Add to Home Screen"
  4. Tap Add in the top right corner
  5. Frank's Kitchen will appear on your home screen
Already Installed?

If the install option doesn't appear after uninstalling:

  • Android: Check Chrome menu (⋮) → Add to Home Screen
  • Android: Go to Chrome Settings → Site Settings → find the app URL → Clear & Reset, then revisit
  • iOS: Must use Safari browser to install
Always open the app via the home screen shortcut, not a browser bookmark, for the best experience and reliable data persistence.
Recipes

Tap any recipe card to expand the full recipe including ingredients, steps, and notes. Use the category filter pills at the top to browse by meal type — Breakfast, Lunch, Dinner, or Dessert. Filter by appliance using the Chef IQ + Ninja AF button at the top right. Tap the star on any recipe card to add it to your Favorites. Tap the pencil icon to rename a recipe. Tap the trash icon inside a recipe to delete it.

Adding Your Own Recipe

Tap the "+ Add Recipe" button at the bottom left of the Recipes tab. Fill in the recipe name, category, appliance, cook time, difficulty, description, ingredients, steps, and notes. Tap Save when done. Your recipe will appear in the list immediately and can be edited or deleted at any time.

Step Timers

Inside any recipe, steps that have a time associated with them show a Preset timer button and a Custom timer button side by side. Tap Preset to start the suggested time. Tap Custom to enter your own time. Multiple timers can run simultaneously across different steps. When a timer hits zero it will alert based on your Ding Settings. Tap "I Got It" to dismiss.

Shopping List

Tap the "+ Add Item" button at the bottom left of the Shopping tab to add a new item. Assign it a category when adding. Tap an item to check it off as bought — it will appear struck through. Use the category filter pills to browse by category. Use the search icon to find a specific item quickly.

Next Run Mode

Tap the cart icon on any shopping list item to flag it for your next shopping run. Toggle between Full List and Next Run views using the button at the top of the Shopping tab. Next Run view shows only your flagged items in a clean flat list — perfect for in-store use. Checking an item in Next Run also checks it in Full List.

Shopping List Actions
  • Remove Bought — deletes all checked items from Full List
  • Clear Full — unchecks all items in Full List
  • Clear Next — unchecks all items in Next Run view only
  • Remove Next — removes all cart flags, clears Next Run list while keeping items in Full List
Settings

Access Settings via the gear icon. From here you can:

  • Manage and reorder shopping categories
  • Set your default opening tab
  • Configure Ding Settings for step timer alerts
  • Export or import a full backup of your data
  • View storage usage
  • Remove all items or all recipes if needed
